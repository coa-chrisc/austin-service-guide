# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies to issues, pull requests, discussions, and any other space where people take part in the project.

## Reporting

To report unacceptable behavior, contact a project maintainer privately through GitHub. Please do not post it in a public issue or pull request. Maintainers enforce the Covenant as described in its Enforcement Guidelines.

Security vulnerabilities are a separate matter. Use GitHub's "Report a vulnerability" as described in [SECURITY.md](SECURITY.md#reporting-a-vulnerability).
